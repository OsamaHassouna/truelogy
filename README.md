# Truelogy Residence

Landing site for **Truelogy Residence | ترولوجي ريزيدنس**, a residential real-estate project. Arabic-first.

## Stack

Static HTML, CSS, vanilla JavaScript with a lightbox-based gallery. No build step, no framework.

## Run locally

```bash
npx serve .
```

Open `http://localhost:3000`.

## Status

Active. Real shipped landing page.
